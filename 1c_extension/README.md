# Расширение 1С «ИнтеграцияTMS» — выдача документов в TMS

HTTP-сервис в расширении конфигурации (основную УНФ не трогает, поддержка остаётся).
Отдаёт по запросу TMS: **Счёт PDF**, **УПД PDF**, **УПД XML (ЭДО)**.

Маршруты (на той же публикации, что OData):
```
GET /grach_unf/hs/tms/print?type=invoice&ref=<guid СчетНаОплату>   → application/pdf
GET /grach_unf/hs/tms/print?type=upd&ref=<guid РасходнойНакладной> → application/pdf
GET /grach_unf/hs/tms/edo?ref=<guid РасходнойНакладной>            → application/xml
```

Состав файлов:
```
ИнтеграцияTMS/
  Configuration.xml                                  ← корень расширения
  CommonModules/
    ИнтеграцияTMSСервер.xml
    ИнтеграцияTMSСервер/Ext/Module.bsl               ← генерация PDF + XML
  HTTPServices/
    tms.xml
    tms/Ext/Module.bsl                               ← точки входа HTTP
```

---

## Вариант 1 — загрузить из файлов (быстро)

1. Конфигуратор → «Конфигурация → Расширения конфигурации» → создать новое
   расширение (имя `ИнтеграцияTMS`, назначение «Дополнение/Customization»).
2. Сделать его активным/текущим → «Конфигурация → Загрузить конфигурацию из
   файлов…» → указать папку `ИнтеграцияTMS`.
3. «Обновить конфигурацию базы данных» (F7).

> Если загрузка из файлов ругается на формат/версию (XML собран вручную) —
> используйте Вариант 2, он надёжнее. Код модулей в обоих случаях один и тот же.

## Вариант 2 — собрать в Конфигураторе (надёжно, ~10 мин)

1. Создать расширение `ИнтеграцияTMS` (назначение «Дополнение»).
2. Добавить **Общий модуль** `ИнтеграцияTMSСервер` (флаги: Сервер = да, Внешнее
   соединение = да; Клиент/Сервер вызова — нет). Вставить код из
   `CommonModules/ИнтеграцияTMSСервер/Ext/Module.bsl`.
3. Добавить **HTTP-сервис** `tms`, корневой URL `tms`. В нём два шаблона URL:
   - `print` (шаблон `/print`) → метод `printGET`, HTTP-метод GET, обработчик `ПечатьGET`;
   - `edo` (шаблон `/edo`) → метод `edoGET`, HTTP-метод GET, обработчик `ЭДОGET`.
   В модуль HTTP-сервиса вставить код из `HTTPServices/tms/Ext/Module.bsl`.
4. «Обновить конфигурацию базы данных» (F7).

## После сборки (оба варианта)

5. **Публикация**: убедиться, что база опубликована на веб-сервере с включёнными
   **HTTP-сервисами** и сервис `tms` входит в состав публикации (при необходимости
   переопубликовать). OData уже работает → публикация есть.
6. **Проверить** в браузере (под пользователем 1С), подставив реальный GUID:
   ```
   http://srv4.life-it.pro/grach_unf/hs/tms/print?type=invoice&ref=<guid-счёта>
   ```
   Должен скачаться PDF. Аналогично `type=upd` и `/edo` для расходной накладной.

## Что уточнить (помечено «# УТОЧНИТЬ» в Module.bsl)

- **Имена макетов печати** счёта и УПД (зависят от редакции УНФ).
- **Выгрузка УПД в XML**: подставить вызов того же механизма, что команда
  «ЭДО → Выгрузить электронный документ в файл» на расходной накладной. Если такой
  команды в базе нет — формат ЭДО не подключён, сообщите об этом (XML будем
  формировать на стороне TMS отдельным этапом).

Готово — как только три URL отдают файлы, TMS-сторона их подхватит автоматически.
