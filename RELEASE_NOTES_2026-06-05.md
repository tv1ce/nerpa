# TMS — Обновление 05.06.2026

## Заказы
- **Кнопка «Создать похожий»** — копирует заказ с теми же позициями, клиентом и перевозчиком. Статус — черновик, дата — сегодня, номер новый.
- **Просроченные заказы** — если дата доставки прошла, а заказ не закрыт, строка подсвечивается красным. Новый фильтр «Просроченные».
- **Расширенные фильтры** — по диапазону дат, клиенту, перевозчику и типу оплаты.

## Склад
- **Автосписание при сборке** — при нажатии «Собран» система сама создаёт расход по всем позициям заказа.

## Счета
- **Расширенные фильтры** — по диапазону дат, клиенту, чекбокс «Просроченные».

## Договора
- **Автоперевод в «Истёк»** — при старте сервера и каждый час договора с истёкшей датой автоматически переходят в статус «Истёк».

## Контрагенты
- **Проверка дублей по ИНН** — при вводе ИНН система сразу предупреждает, если контрагент с таким ИНН уже есть.

## Отчёт «Выручка»
- **Прогноз выполнения плана** — «при текущем темпе закроем на X%» с прогнозом суммы на конец месяца.
- **Сравнение с прошлым годом** — текущий месяц против того же месяца год назад, с динамикой в %.

## Логистика
- **Доля затрат в выручке (%)** — по каждому периоду (неделя/месяц/год). Виден рост эффективности логистики.

## Дебиторка
- **Группировка по контрагентам** — счета свёрнуты по клиентам: «Клиент — итого, сколько просрочено». Раскрытие по клику. Главные должники — сверху.

## Настройки и профиль
- **Редактирование пользователя** — смена роли и пароля существующего пользователя.
- **Личный профиль** — каждый сотрудник может сменить ФИО, пароль и указать день рождения (клик по имени вверху справа).

## Уведомления
- **Кликабельные уведомления** — клик по уведомлению ведёт прямо на нужную страницу.

## Табло цеха
- **Дни рождения сотрудников** — в день рождения на табло появляется праздничный баннер с именем. Блок «Скоро ДР» показывает ближайшие дни рождения на неделю вперёд.
