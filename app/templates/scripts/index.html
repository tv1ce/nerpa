Как это работает

В ссылке нет ни имени, ни телефона — только номер карточки. Имя, компанию и телефон NERPA подтянет из Bitrix24 сама, и подстановки {{ '{{Имя}}' }}, {{ '{{Компания}}' }}, {{ '{{Телефон}}' }} в тексте скрипта заменятся на актуальные данные. Заполненные менеджером поля по завершении разговора уедут обратно в эту же карточку.

Как поставить в Bitrix24
  1. В карточке сделки добавьте пользовательское поле типа «Ссылка», например «Скрипт разговора»
  2. На нужной стадии создайте робота «Изменить документ» и запишите в это поле ссылку выше
  3. Вместо {{ '{{ID}}' }} подставьте значение из списка полей робота — идентификатор сделки. Руками его лучше не печатать: в разных порталах поле называется по-разному

Импорт скриптов
Документы (.docx, .txt, .md) — каждый файл станет отдельным скриптом: заголовки превращаются в шаги, строки вида «Да → Вопрос 5» — в ответы с переходами.
Выгрузка HyperScript (.json) — шаги, связи, ветвление и оформление переносятся один в один; в одном файле может быть сразу вся библиотека скриптов.
