{# Bitrix24 #}
Bitrix24 CRM

1. Входящий вебхук (Bitrix24 → сюда данные не идут, а TМS ходит в Bitrix24): Битрикс24 → Приложения → Разработчикам → Другое → Входящий вебхук. Права: crm. Скопируйте URL вида https://nuttinelle.bitrix24.ru/rest/1/xxxxxxxxxxxxx/ в поле ниже.
2. Ключ приёма сделок — на сервере TMS в .env задайте BITRIX_PUSH_KEY (сгенерировать: python -c "import secrets; print(secrets.token_urlsafe(32))").
3. Правило автоматизации на стадии «Заказ согласован»: откройте нужную воронку сделок → настройте роботов на этой стадии → добавьте робота «Вебхук» (Webhook) с параметрами:
URL: https://ваш-tms-домен/api/bitrix/webhook/deal-approved?key=ВАШ_BITRIX_PUSH_KEY&deal_id={=Document:ID}, метод POST.
4. Нажмите «Создать UF-поля» ниже — TMS создаст в сделках два булевых поля-плашки «Оплачено (TMS)» и «Доставлено (TMS)», которые можно добавить в карточку/список сделки через настройку вида канбана в Bitrix24.
5. Выберите стадии для «Счёт оплачен» и «Отгрузка» — TMS будет двигать сделку автоматически при оплате счёта и сборке заказа.
