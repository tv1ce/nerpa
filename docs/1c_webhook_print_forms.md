# Webhook 1С → TMS: счета и печатные формы (Счёт, УПД)

Сценарий: пользователь в 1С:УНФ нажимает **«Провести»** на счёте или расходной
накладной → 1С формирует печатную форму в PDF и **сама шлёт** её в TMS вместе с
метаданными. TMS дублирует счёт в карточку (с привязкой к заказу) и прикладывает
PDF к заказу (со сжатием).

OData стандартного интерфейса печатные формы не отдаёт — поэтому 1С их толкает
сама (push). Код ниже кладётся в **расширение конфигурации** (основную конфу УНФ
не трогаем, поддержка не снимается).

---

## 1. Контракт вебхука (сторона TMS — уже реализовано)

```
POST  {база TMS}/sync/1c/hook/document
Заголовок:   X-TMS-Token: <токен из Настройки → Интеграция 1С:УНФ>
Тело:        multipart/form-data
```

Поля формы:

| Поле               | Обяз. | Описание                                                            |
|--------------------|:-----:|---------------------------------------------------------------------|
| `doc_type`         |  да   | `invoice` (счёт), `upd` (УПД), `tn` (ТН)                            |
| `doc_ref`          |  да   | Ref_Key документа 1С (GUID строкой) — ключ идемпотентности         |
| `number`           |  —    | Номер документа, напр. `НФНФ-000022`                               |
| `doc_date`         |  —    | Дата документа, ISO `ГГГГ-ММ-ДД`                                   |
| `amount`           |  —    | Сумма документа (число)                                            |
| `order_ref`        |  —    | Ref_Key **заказа покупателя** 1С — по нему TMS находит заказ       |
| `counterparty_ref` |  —    | Ref_Key контрагента 1С (если заказ не передан)                    |
| `items_json`       |  —    | JSON-массив строк счёта (см. ниже)                                 |
| `file`             |  —    | Файл PDF печатной формы                                            |

`items_json` — массив объектов:
```json
[{"name":"Орешки", "quantity":10, "unit":"шт", "price":100, "vat_rate":20,
  "discount_pct":0, "product_ref":"<guid номенклатуры 1С>"}]
```

Ответ: `{"ok": true, "invoice_id": 123, "file_id": 45}`.
Идемпотентность: повторная присылка того же `doc_ref` обновляет счёт и заменяет
прежний PDF, дублей не создаёт.

> Заказ в TMS находится по `order_ref` (он же `Order.external_id_1c`, который TMS
> проставила при выгрузке заказа в 1С). Поэтому заказ должен быть сначала выгружен
> из TMS в 1С — тогда привязка PDF/счёта к заказу сработает.

## 2. Сторона 1С — расширение конфигурации

### 2.1. Общий модуль `ИнтеграцияTMS` (Сервер, Вызов сервера)

```bsl
// Параметры подключения. Лучше вынести в константы/реквизиты, тут — для примера.
Функция АдресВебхука() Экспорт
    Возврат "https://tms.example.ru/sync/1c/hook/document";
КонецФункции

Функция ТокенВебхука() Экспорт
    Возврат "ВСТАВЬТЕ_ТОКЕН_ИЗ_НАСТРОЕК_TMS";
КонецФункции

// Главная точка входа: отправить документ (счёт/расходную) в TMS.
// ТипДок: "invoice" | "upd" | "tn"
Процедура ОтправитьДокумент(Ссылка, ТипДок) Экспорт
    Попытка
        ДанныеPDF = СформироватьПечатнуюФормуPDF(Ссылка, ТипДок);
        Метаданные = СобратьМетаданные(Ссылка, ТипДок);
        ОтправитьМультипарт(Метаданные, ДанныеPDF);
    Исключение
        // Не роняем проведение из-за интеграции — только пишем в журнал
        ЗаписьЖурналаРегистрации("ИнтеграцияTMS", УровеньЖурналаРегистрации.Ошибка,
            , Ссылка, ОписаниеОшибки());
    КонецПопытки;
КонецПроцедуры
```

### 2.2. Формирование печатной формы в PDF

Печать вызывается так же, как по кнопке «Печать»: получаем `ТабличныйДокумент`
через подсистему печати БСП и пишем его в поток как PDF.

```bsl
// Возвращает ДвоичныеДанные PDF.
Функция СформироватьПечатнуюФормуPDF(Ссылка, ТипДок) Экспорт
    // Имя команды печати зависит от конфигурации/документа.
    // Уточните у вашего 1С-специалиста реальные значения (Конфигуратор →
    // модуль менеджера документа → процедуры печати, либо команда печати на форме).
    Если ТипДок = "invoice" Тогда
        МенеджерПечати = "Документ.СчетНаОплату";
        ИмяМакета      = "СчетНаОплату";        // напр. "Счет", "СчетНаОплату"
    ИначеЕсли ТипДок = "upd" Тогда
        МенеджерПечати = "Документ.РасходнаяНакладная";
        ИмяМакета      = "УПД";                  // универсальный передаточный документ
    Иначе
        МенеджерПечати = "Документ.РасходнаяНакладная";
        ИмяМакета      = "ТоварнаяНакладная";
    КонецЕсли;

    МассивОбъектов = Новый Массив;
    МассивОбъектов.Добавить(Ссылка);

    // БСП: УправлениеПечатью.СформироватьПечатныеФормы
    КоллекцияПФ      = Новый Массив; КоллекцияПФ.Добавить(ИмяМакета);
    ПараметрыПечати  = Новый Структура;
    ТабличныеДокументы = Новый СписокЗначений;

    УправлениеПечатью.ПечататьНаборФорм(
        КоллекцияПФ, МассивОбъектов, ТабличныеДокументы, , , );

    // Берём первый сформированный табличный документ
    ТабДок = Неопределено;
    Для Каждого Элемент Из ТабличныеДокументы Цикл
        ТабДок = Элемент.Значение;
        Прервать;
    КонецЦикла;
    Если ТабДок = Неопределено Тогда
        ВызватьИсключение "Печатная форма не сформирована: " + ИмяМакета;
    КонецЕсли;

    // Табличный документ → PDF в поток в памяти
    Поток = Новый ПотокВПамяти;
    ТабДок.Записать(Поток, ТипФайлаТабличногоДокумента.PDF);
    Поток.Закрыть();
    Возврат Поток.ЗакрытьИПолучитьДвоичныеДанные();
КонецФункции
```

> Если в вашей УНФ нет `УправлениеПечатью.ПечататьНаборФорм`, используйте
> `УправлениеПечатью.СформироватьПечатныеФормы(...)` или вызов процедуры `Печать`
> из модуля менеджера документа — итог один: получить `ТабличныйДокумент`, затем
> `ТабДок.Записать(Поток, ТипФайлаТабличногоДокумента.PDF)`.

### 2.3. Метаданные документа

```bsl
Функция СобратьМетаданные(Ссылка, ТипДок) Экспорт
    Об = Ссылка.ПолучитьОбъект();
    М = Новый Структура;
    М.Вставить("doc_type", ТипДок);
    М.Вставить("doc_ref",  XMLСтрока(Ссылка.УникальныйИдентификатор())); // GUID строкой
    М.Вставить("number",   Об.Номер);
    М.Вставить("doc_date", Формат(Об.Дата, "ДФ=yyyy-MM-dd"));
    М.Вставить("amount",   Формат(Об.СуммаДокумента, "ЧДЦ=2; ЧРД=.; ЧГ=0"));

    // Ссылка на заказ покупателя (по нему TMS привяжет к заказу).
    // Реквизит-источник зависит от конфигурации: Сделка / Заказ / ДокументОснование.
    ЗаказСсылка = Неопределено;
    Если Об.Свойство("Сделка") И ТипЗнч(Об.Сделка) = Тип("ДокументСсылка.ЗаказПокупателя") Тогда
        ЗаказСсылка = Об.Сделка;
    ИначеЕсли Об.Свойство("Заказ") Тогда
        ЗаказСсылка = Об.Заказ;
    КонецЕсли;
    Если ЗначениеЗаполнено(ЗаказСсылка) Тогда
        М.Вставить("order_ref", XMLСтрока(ЗаказСсылка.УникальныйИдентификатор()));
    КонецЕсли;

    Если ЗначениеЗаполнено(Об.Контрагент) Тогда
        М.Вставить("counterparty_ref", XMLСтрока(Об.Контрагент.УникальныйИдентификатор()));
    КонецЕсли;

    // Позиции (только для счёта)
    Если ТипДок = "invoice" И Об.Свойство("Товары") Тогда
        Строки = Новый Массив;
        Для Каждого ТЧ Из Об.Товары Цикл
            С = Новый Структура;
            С.Вставить("name",         СокрЛП(ТЧ.Номенклатура));
            С.Вставить("quantity",     ТЧ.Количество);
            С.Вставить("unit",         ?(ЗначениеЗаполнено(ТЧ.Свойство("Единица")), СокрЛП(ТЧ.Единица), "шт"));
            С.Вставить("price",        ТЧ.Цена);
            С.Вставить("vat_rate",     20);
            С.Вставить("discount_pct", ?(ТЧ.Свойство("ПроцентСкидкиНаценки"), ТЧ.ПроцентСкидкиНаценки, 0));
            С.Вставить("product_ref",  XMLСтрока(ТЧ.Номенклатура.УникальныйИдентификатор()));
            Строки.Добавить(С);
        КонецЦикла;
        М.Вставить("items_json", ЗаписатьJSON_Строкой(Строки));
    КонецЕсли;

    Возврат М;
КонецФункции

Функция ЗаписатьJSON_Строкой(Значение) Экспорт
    Запись = Новый ЗаписьJSON;
    Запись.УстановитьСтроку();
    ЗаписатьJSON(Запись, Значение);
    Возврат Запись.Закрыть();
КонецФункции
```

### 2.4. Отправка multipart/form-data

```bsl
Процедура ОтправитьМультипарт(Метаданные, ДанныеPDF) Экспорт
    Граница = "----TMS" + СтрЗаменить(Строка(Новый УникальныйИдентификатор()), "-", "");
    Тело = Новый ПотокВПамяти;
    Запись = Новый ЗаписьДанных(Тело, КодировкаТекста.UTF8);

    // Текстовые поля
    Для Каждого КЗ Из Метаданные Цикл
        Если КЗ.Значение = Неопределено Тогда Продолжить; КонецЕсли;
        Запись.ЗаписатьСтроку("--" + Граница + Символы.ВК + Символы.ПС);
        Запись.ЗаписатьСтроку("Content-Disposition: form-data; name=""" + КЗ.Ключ + """"
            + Символы.ВК + Символы.ПС + Символы.ВК + Символы.ПС);
        Запись.ЗаписатьСтроку(Строка(КЗ.Значение) + Символы.ВК + Символы.ПС);
    КонецЦикла;

    // Файл PDF
    Если ДанныеPDF <> Неопределено Тогда
        Запись.ЗаписатьСтроку("--" + Граница + Символы.ВК + Символы.ПС);
        Запись.ЗаписатьСтроку("Content-Disposition: form-data; name=""file""; filename=""form.pdf"""
            + Символы.ВК + Символы.ПС);
        Запись.ЗаписатьСтроку("Content-Type: application/pdf" + Символы.ВК + Символы.ПС
            + Символы.ВК + Символы.ПС);
        Запись.Закрыть();
        // дописываем бинарь файла
        ЧтениеФайла = ДанныеPDF.ОткрытьПотокДляЧтения();
        БуферФайла  = ЧтениеФайла.ПрочитатьВБуферДвоичныхДанных();
        Тело.Записать(БуферФайла, 0, БуферФайла.Размер);
        ЧтениеФайла.Закрыть();
        ХвостЗапись = Новый ЗаписьДанных(Тело, КодировкаТекста.UTF8);
        ХвостЗапись.ЗаписатьСтроку(Символы.ВК + Символы.ПС + "--" + Граница + "--"
            + Символы.ВК + Символы.ПС);
        ХвостЗапись.Закрыть();
    Иначе
        Запись.ЗаписатьСтроку("--" + Граница + "--" + Символы.ВК + Символы.ПС);
        Запись.Закрыть();
    КонецЕсли;

    ТелоЗапроса = Тело.ЗакрытьИПолучитьДвоичныеДанные();

    // HTTP POST
    URL = АдресВебхука();
    Соединение = Новый HTTPСоединение(
        СтрЗаменить(СтрЗаменить(URL, "https://", ""), "http://", ""),
        ?(Найти(URL, "https://") > 0, 443, 80), , , , 30,
        ?(Найти(URL, "https://") > 0, Новый ЗащищенноеСоединениеOpenSSL(), Неопределено));

    ПутьРесурса = Сред(URL, Найти(URL, "/sync"));
    Запрос = Новый HTTPЗапрос(ПутьРесурса);
    Запрос.Заголовки.Вставить("X-TMS-Token", ТокенВебхука());
    Запрос.Заголовки.Вставить("Content-Type", "multipart/form-data; boundary=" + Граница);
    Запрос.УстановитьТелоИзДвоичныхДанных(ТелоЗапроса);

    Ответ = Соединение.ОтправитьДляОбработки(Запрос);
    Если Ответ.КодСостояния <> 200 Тогда
        ВызватьИсключение "TMS вернул " + Ответ.КодСостояния + ": " + Ответ.ПолучитьТелоКакСтроку();
    КонецЕсли;
КонецПроцедуры
```

### 2.5. Триггер на проведении

Вариант, дающий мгновенную отправку «по кнопке Провести», без отправки HTTP внутри
транзакции проведения — через **подписку на событие `ПриЗаписи`** (после успешной
записи; срабатывает при интерактивном проведении тоже):

```bsl
// Подписка на событие: Источник = ДокументСсылка.СчетНаОплату, Событие = ПриЗаписи
Процедура СчетПриЗаписи(Источник, Отказ) Экспорт
    Если Источник.Проведен Тогда
        ИнтеграцияTMS.ОтправитьДокумент(Источник.Ссылка, "invoice");
    КонецЕсли;
КонецПроцедуры

// Подписка: Источник = ДокументСсылка.РасходнаяНакладная, Событие = ПриЗаписи
Процедура РасходнаяПриЗаписи(Источник, Отказ) Экспорт
    Если Источник.Проведен Тогда
        ИнтеграцияTMS.ОтправитьДокумент(Источник.Ссылка, "upd");
    КонецЕсли;
КонецПроцедуры
```

> Альтернатива, если не хотите HTTP в момент записи: сложить ссылку в очередь
> (регистр сведений «ОчередьОтправкиВTMS») в `ПриЗаписи`, а реальную отправку делать
> регламентным заданием раз в 1–2 минуты. Надёжнее под нагрузкой, но не «мгновенно».

## 3. Что настроить один раз

1. **TMS:** Настройки → Интеграция 1С:УНФ → «Сгенерировать токен». Скопировать
   URL вебхука и токен.
2. **1С:** создать расширение, добавить общий модуль `ИнтеграцияTMS` (код выше),
   подставить `АдресВебхука()` и `ТокенВебхука()`, добавить две подписки на событие.
3. Уточнить с 1С-специалистом реальные имена макетов печати (`ИмяМакета`) и реквизит
   ссылки на заказ (`Сделка`/`Заказ`) — они зависят от вашей редакции УНФ.
4. Проверить: заказ должен быть предварительно выгружен из TMS в 1С (чтобы у заказа
   был GUID, по которому привязывается счёт и PDF).
